Quick start

Using the current dashboard

01

Define pastures

Draw polygons on the map or upload a GeoJSON file. Each pasture can be named, edited, removed, and exported. Geometry remains in local browser storage.

02

Choose a data path

Public mode represents satellite-supported reconnaissance. UAV mode stages the additional inputs needed for property-specific forage-quality work.

03

Set planning inputs

Enter animal class, head count, average weight, grazing days, and allowable use to calculate planned herd demand in animal unit months.

04

Request an estimate

The interface validates project inputs and then stops at model inference. This is expected until validated prediction services are connected.

Target layers

What the planned measurements represent

Units and reporting conventions will be finalized with each model’s validation protocol.

Biomass

Forage quantity

Estimated aboveground dry matter over a defined observation period. The initial product path is intended to use public satellite imagery, with UAV data available for higher-resolution projects.

Crude protein / nitrogen

Forage quality

A laboratory-calibrated estimate related to plant nitrogen concentration and nutritional value. Planned for the private UAV workflow.

NDF

Forage quality

Neutral detergent fiber, a measure of structural plant material associated with intake and digestibility. Planned for the private UAV workflow.

Silica

Forage quality

Plant silica concentration, included because it can affect palatability and forage value and is central to the initial ventenata research.

Ventenata dubia

Bio-Invaders

Occurrence or probability of the invasive annual grass ventenata. Final output type, resolution, and detection threshold will depend on validation results.

Data and limitations

Every map layer needs context.

ForageWatch is designed to retain the information needed to interpret a result, not just render a colored surface.

Source
Sensor or collection, acquisition date, spatial resolution, preprocessing, and pasture coverage.
Model
Target definition, version, training domain, validation data, and known limits.
Confidence
Uncertainty or quality flags that indicate where a result should not be treated as decision-ready.
Privacy
Public satellite workflows and private property-specific UAV data follow different access paths.
