Not yet. The prediction pipeline intentionally stops with a “no validated model available” status. Zubr is developing the calibration data, validation protocols, and processing services required before model outputs can be treated as usable measurements.

The current product plan includes biomass, crude protein/nitrogen, neutral detergent fiber (NDF), silica, and invasive-plant occurrence beginning with Ventenata dubia. The final availability, resolution, and units of each layer will depend on validation results.

Public satellite imagery supports repeat coverage over large areas and is a practical path for compatible measurements such as biomass. UAV hyperspectral and lidar data can capture finer, property-specific information needed for detailed forage-quality work. UAV data also needs a private account and storage model that the current static prototype does not yet provide.

For the primary current-condition workflow, the system is intended to select the newest observations that pass coverage and quality checks. Historical date ranges are more useful for a dedicated comparison workflow and are not part of the current prototype.

The current AUM figure is a planning calculation based on animal class, head count, average body weight, and planned grazing days. It is not a stocking recommendation. A supported-head-count estimate will require a validated biomass layer plus management assumptions such as allowable use.

In the current prototype, pasture geometry and settings are stored only in the local browser. They are not uploaded to Zubr. Clearing browser storage can remove them, so export important boundaries as GeoJSON. Cloud projects and organization accounts are planned but not connected.
